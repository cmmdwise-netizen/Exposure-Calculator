# Field Exposure & Dynamic Range Calculator

A lightweight, mobile-friendly web utility designed for landscape and nature photographers to calculate precise exposure adjustments and dynamic range strategies in the field.

## Features
- **Scene-Specific Adjustments:** Tailored calculations for sunsets, waterfalls, general landscapes, and nightscapes.
- **Highlight Protection Bias:** Easily apply EV compensation (e.g., -2/3 EV) to protect critical highlights in high-contrast scenes.
- **Copy Results:** One-tap button to copy your exposure settings to your device clipboard.
- **AI Integration:** Direct link to consult Gemini for advanced field advice.
- **Offline Capable:** Runs locally in any web browser or via GitHub Pages.

## Usage
Simply open the hosted GitHub Pages link on your phone or computer, select your scene type, enter your base meter readings, and calculate your target settings!
